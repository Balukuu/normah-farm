Quality, handling & traceability

From field record to dispatch document.

Every stage of the handling chain, in order, and what's recorded at each one. Where a step is planned rather than running today, it's marked plainly.

Field and plot record

Each block is tracked against the plot it was planted on, the crop and season it carries, and the inputs applied.

Plot ID, crop, season, planting date

Harvest

Combine harvesters bring in cereal crops; harvest timing is set by the season's planting record and crop maturity.

Harvest date, plot ID, crop

Cleaning

Grain is cleaned to remove chaff, debris and off-types before drying and grading.

Batch ID

Drying and moisture check

Moisture is checked against a target for each crop before grain moves to grading and storage.

Moisture reading Verify — per-crop targets

Grading

Cleaned, dried grain is sorted to grade before bagging.

Grade, batch ID

Bagging

Graded grain is bagged for storage and onward dispatch.

Bag count, weight, batch ID

Warehouse storage

Bagged grain is held in the farm's 450 sqm warehouse ahead of dispatch.

Warehouse location, quantity, date in

Dispatch documentation

Each outgoing shipment carries documentation tying it back to the batches and plots it came from.

Dispatch note, quantity, destination, date

A silo, weighbridge and grading facility are planned

A silo with a processing area, a walk-in bagging area, a washing and grading area with stainless steel tables, and a weighbridge are planned additions to this chain Planned. None of this is built yet, and no date is set — today's handling runs through the farm's existing warehouse and field equipment.
